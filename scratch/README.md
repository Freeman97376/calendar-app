# Scratch Workspace

Use this folder for temporary files, generated diagnostics, throwaway outputs, and local experiment artifacts.

Rules:

- Put all temporary files under `scratch/`.
- Put all one-off/manual test scripts under `scratch/test-scripts/`.
- Do not place scratch files in `src/`, `tests/`, `Office/`, or the project root.
- Promote useful scripts into the real test suite only when they are stable and intentional.

Most files in this folder are ignored by Git.
